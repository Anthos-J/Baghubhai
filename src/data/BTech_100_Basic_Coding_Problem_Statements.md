# 100 B.Tech Programming Practice Problems

## Java • C • Python

This collection is intentionally focused on **small,
implementation-oriented B.Tech programming/lab problems** rather than
large software projects. The problems cover the kinds of programs
commonly used to learn programming fundamentals, loops, functions,
arrays, strings, matrices, recursion, patterns, number theory,
searching, sorting, and basic data structures.

All 100 problems can be implemented in **C, Java, and Python**.

------------------------------------------------------------------------

# 1. Basic Input, Output, Operators and Conditions

### 1. Add Two Numbers

Write a program to accept two integers and print their sum.

### 2. Arithmetic Operations

Accept two numbers and perform addition, subtraction, multiplication,
division, and modulus operations.

### 3. Swap Two Numbers

Write a program to swap two numbers using a temporary variable and then
demonstrate swapping without a temporary variable.

### 4. Swap Without Third Variable

Swap two integer values using arithmetic or bitwise operations without
using a third variable.

### 5. Simple Calculator

Create a menu-driven calculator that performs `+`, `-`, `*`, `/`, and
`%` based on the operator entered by the user.

### 6. Even or Odd

Determine whether a given integer is even or odd.

### 7. Positive, Negative or Zero

Determine whether a number is positive, negative, or zero.

### 8. Largest of Two Numbers

Read two numbers and print the larger number.

### 9. Largest of Three Numbers

Read three numbers and find the largest using conditional statements.

### 10. Smallest of Three Numbers

Read three numbers and find the smallest without using built-in minimum
functions.

------------------------------------------------------------------------

# 2. Number Programs

### 12. Count Digits

Count the number of digits present in an integer.

### 13. Sum of Digits

### 14. Product of Digits

Calculate the product of all digits of a given number.

### 15. First and Last Digit

### 17. Prime Number

Print all prime numbers between two user-provided limits.

Print all perfect numbers within a specified range.

### 27. Strong Number

Check whether the square of a number ends with the number itself.

### 36. GCD of Two Numbers

### 37. LCM of Two Numbers

Find the least common multiple of two integers using their GCD.

### 38. GCD and LCM of Multiple Numbers

### 39. Power of a Number

### 40. Decimal to Binary

Convert a decimal integer to binary without using a built-in conversion
function.

### 41. Binary to Decimal

Convert a binary number entered as digits into its decimal equivalent.

### 42. Decimal to Octal and Hexadecimal

Convert a decimal number to octal and hexadecimal representations.

### 43. Binary Number of 1s

Count the number of set bits (`1`s) in the binary representation of an
integer.

### 44. Leap Year

Determine whether a given year is a leap year according to the Gregorian

### 45. Number of Days in a Month

# 3. Mathematical Series and Formula-Based Programs

### 46. Sum of Natural Numbers

Calculate the sum of the first `n` natural numbers using both a loop and
the mathematical formula.

### 47. Sum of Even Numbers

Calculate the sum of all even numbers from 1 to `n`.

### 48. Sum of Odd Numbers

Calculate the sum of all odd numbers from 1 to `n`.

### 49. Harmonic Series

Generate the series `1 + 1/2 + 1/3 + ... + 1/n` and calculate its sum.

### 50. Arithmetic Progression

Generate the first `n` terms of an arithmetic progression for a given
first term and common difference.

### 51. Geometric Progression

Generate the first `n` terms of a geometric progression and calculate
its sum.

### 52. Sum of Squares

Calculate `1² + 2² + 3² + ... + n²`.

### 53. Sum of Cubes

Calculate `1³ + 2³ + 3³ + ... + n³`.

### 54. Sine Series

Approximate `sin(x)` using the Taylor series:

`sin(x) = x - x³/3! + x⁵/5! - x⁷/7! + ...`

Accept `x` and the number of terms from the user. Clearly document
whether `x` is interpreted in radians.

### 55. Cosine Series

Approximate `cos(x)` using the Taylor series:

`cos(x) = 1 - x²/2! + x⁴/4! - x⁶/6! + ...`

Accept `x` and the number of terms.

### 56. Exponential Series

Approximate `e^x` using:

`e^x = 1 + x + x²/2! + x³/3! + ...`

### 57. Logarithm Series

Approximate `ln(1+x)` using its series expansion for an input within the
valid convergence range.

### 58. Sine, Cosine and Tangent Table

For angles from 0 to 90 degrees at a user-selected interval, generate a
table containing sine, cosine, and tangent values.

### 59. Quadratic Equation

Find the roots of `ax² + bx + c = 0` and handle real, repeated, and
complex roots appropriately.

### 60. Distance Between Two Points

Calculate the Euclidean distance between two points `(x1,y1)` and
`(x2,y2)`.

# Implementation Requirement

For every problem, students should ideally provide:

-   Problem statement
-   Algorithm
-   Flowchart or pseudocode
-   Source code
-   Sample input
-   Sample output
-   Time complexity where applicable
-   Space complexity where applicable
-   At least 2--3 test cases
-   Edge-case handling

The same problem should be implemented independently in **C, Java, and
Python** to understand the differences between procedural programming,
object-oriented programming, and high-level scripting.
